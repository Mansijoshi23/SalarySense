Built on real machine learning

Four regression models were trained and compared on the underlying dataset; the strongest performer on held-out data was selected for live predictions.

Linear Regression, Decision Tree, Random Forest, and Gradient Boosting were each trained on the same cleaned dataset and evaluated with MAE, RMSE, and R² on a held-out test split. The best model by R² is the one powering every prediction in this app — see the About page for the exact figures from the last training run.
